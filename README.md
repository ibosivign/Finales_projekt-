## Fikri geliştirmek için kullanacağım araçlar:
> Python: Discord botunu programlamak için.

Visual Studio Code cünkü onun üstünde proglamlicam

Discord Developer Portal Cünkü discord token gerekiyor

Discord.py Botun python ile balantisi

SQLite Ders programi bilgilerini kaydetmek icin 

## Projede şu bölümler bulunacak:
>  
  1. Ögrencileri karsilayan bir bot mesaji. (nazik bisey)
  2. Ögrencilerin butona tiklayarak ders programini görebilmesi. (daha hizli bir giris)
  3. Haftanın tüm günlerine ait derslerin gösterilmesi.
  4. Okul yöneticilerinin ders programını düzenleyebilmesi. (ders olmadinda ya deyisiklerde)
  5. Ögrenciler ve yöneticiler için botun nasıl kullanılacağını anlatan doküman. (ögrensinler diye)
  6. Renkli, düzenli ve kullanımı kolay bir arayüz.(herkesa rahat kulanabilsin diye)
  7. Öğrencilere ödevlerini hatırlatma.(unutmasinlar diye)
  9. Sınav Takvimi(nezaman ne sinavina gircekler diye bir arayüz)
  10. Tatil Takvimi(nezaman tatil oldunu bilsinler diye)
  11. Yardim Butonu(ev ödevinde yardim gerekirse diye)
  12. Hata Kontrolü(yanlislarini düzeltebilsinler diye)
